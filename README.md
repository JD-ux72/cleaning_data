# 🧹 Cleaning Data

A data preprocessing and feature engineering project focused on transforming raw municipal and geospatial datasets into clean, machine-learning-ready data.

## 📌 Project Overview

Raw datasets are rarely ready for analysis. This project demonstrates a complete data preparation workflow using municipal and geographic data collected from public sources.

The objective is to transform inconsistent, incomplete, and unstructured data into a reliable dataset suitable for analytics, visualization, and machine learning applications.

## 🎯 Objectives

* Load and inspect raw datasets
* Identify and handle missing values
* Remove duplicate records
* Standardize column names and formats
* Convert incorrect data types
* Encode categorical variables
* Engineer meaningful features
* Prepare data for machine learning workflows

## 📂 Dataset Sources

Data used in this project was collected from publicly available government and geospatial sources, including:

* Municipal boundary datasets
* Administrative boundary datasets
* Population and demographic data
* Geographic information system (GIS) data

## 🔄 Data Cleaning Pipeline

### 1. Data Loading

* Import raw datasets
* Inspect structure and schema
* Validate records

### 2. Data Cleaning

* Handle missing values
* Remove duplicates
* Correct inconsistent formatting
* Standardize naming conventions

### 3. Data Transformation

* Convert data types
* Normalize values
* Prepare features for analysis

### 4. Feature Engineering

Examples include:

* Population Density
* Infrastructure Pressure Index
* Road Coverage Metrics
* Urbanization Indicators

### 5. Machine Learning Preparation

* Label Encoding
* Feature Scaling
* Data Validation
* Exporting final datasets
